Daybreak attestation probe

Registers a credential with the same options Daybreak requests — cross-platform attachment, discoverable, user verification required, attestation: "direct" — and decodes what the security key actually returned. The registration is also recorded server-side in registrations.jsonl.

    What to look for
    

      
        
x5c presentA hardware key ships its attestation certificate. A software
          or synced passkey typically returns fmt: "none" or self-attestation with
          no chain.

        
AAGUIDMust be the AAGUID the selected profile presents. This is the value
          a relying party maps through the FIDO MDS.

        
BE / BSBoth clear means the credential is device-bound. A set BE bit means
          the credential claims to be backup-eligible, i.e. a synced passkey.

        
UVMust be set: the request asked for userVerification: "required".

        
FlagsAT set means attested credential data is included; ED is the
          extension-data flag.
